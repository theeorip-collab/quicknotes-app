# QuickNotes

QuickNotes is a simple note-taking web app that allows users to create, organise, search and delete notes. Notes can be assigned to Personal, Work or Study categories, and they are saved in the browser so they remain available after refreshing the page.

## Features

- Add notes with different categories
- Personal, Work and Study categories
- Delete notes
- Search notes as you type
- Validation for empty notes
- 200-character note limit
- Note count display
- Save notes using localStorage
- Responsive design for smaller screens

## How to Run Locally

1. Clone the repository from GitHub.
2. Open the `quicknotes-app` folder in VS Code.
3. Open `index.html` with Live Server.
4. Use the app in your web browser.
